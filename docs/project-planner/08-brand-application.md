# Project Profile brand application

Source: `Brand Guidelines - Project Profile`, v2025.1.

## Surface selection

- The public landing page uses the marketing dialect: Montserrat display type,
  lowercase headings ending with a period, and confident yellow brand fields.
- The planner, procurement, contractor portal, summaries and authentication
  screens use the reporting UI dialect: Inter, sentence case, generous
  whitespace and sparing yellow accents.
- The client PDF remains intentionally black and white to satisfy the approved
  export specification. Helvetica is the supported Inter substitute in the PDF
  renderer.

## Component rules

- Primary actions use accent yellow with near-black text.
- Cards are white with a 1px grey border, 10-14px radius and a subtle
  pure-black shadow.
- Inputs use a 6px radius and a visible yellow focus ring.
- Icons remain outline-only Lucide icons and follow the surrounding text
  colour. Yellow is reserved for active or emphasized states.
- Charts are flat and use yellow, blue, green, grey and near-black only.
- UI headings and labels use sentence case without terminal periods.
- Marketing display headings are lowercase and end with a period.
